# Бот-счётчик постов админов каналов

Считает, сколько постов опубликовал каждый админ Telegram-канала. Данные хранятся в PostgreSQL.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `DATABASE_URL` | строка подключения PostgreSQL (`postgresql://user:pass@host:5432/db`). Если базе нужен SSL, добавь `?sslmode=require` |
| `ADMIN_IDS` | Telegram ID владельцев через запятую (узнать: @userinfobot). Получают обращения и могут делать рассылку |
| `TZ_NAME` | часовой пояс для «сегодня», по умолчанию `Asia/Vladivostok` |

Таблицы создаются автоматически при первом запуске.

## Запуск

```
pip install -r requirements.txt
python bot.py
```

## Подключение канала

1. Добавь бота в канал **администратором**.
2. Включи в канале **«Подписывать сообщения»**. Без этого все посты попадут в «Без подписи».
3. Считаются только посты, опубликованные после добавления бота.

## Как пользоваться

- `/start` — меню: **Статистика**, **Поддержка**, **Предложение** (и **Рассылка** для владельцев).
- **Статистика** (или `/top`) — кнопками выбираешь канал, затем период: Сегодня / 7 дней / 30 дней / Всё время. Показываются только каналы, где ты админ.
- **Поддержка / Предложение** — пользователь пишет сообщение, оно приходит владельцам (`ADMIN_IDS`). Владелец отвечает реплаем на это сообщение, и ответ уходит пользователю. Все обращения сохраняются в таблице `feedback`.
- **Панель владельца** (кнопка в меню или `/owner`, только `ADMIN_IDS`; другим людям кнопка не показывается и команды не работают):
  - общая статистика бота: пользователи, заблокировавшие, каналы, посты за сегодня и 7 дней, число обращений;
  - **Рассылка** (или `/broadcast`) — всем, кто запускал бота. Принимает текст, фото, видео и т.д. как есть, перед отправкой просит подтверждение, в конце присылает отчёт. Заблокировавшие бота помечаются и пропускаются;
  - **Экспорт CSV** — файл со всеми постами (канал, автор, день, количество) или список пользователей. Файлы открываются в Excel и Google Таблицах.
- `/cancel` — отмена текущего действия.

## Особенности

- Альбом из нескольких фото/видео считается за один пост.
- Админы различаются по подписи (имя в профиле). Если админ сменит имя, он будет считаться новым автором.
- Редактирование постов не учитывается.
- Проверка «ты админ этого канала» кэшируется на 5 минут и выполняется параллельно по всем каналам.
